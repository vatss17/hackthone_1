# Translation glossary (Hindi and Gujarati)

Use these terms everywhere so the interface reads the same on every page. Technical identifiers are never translated:
HS and HSN codes, polymer names and grades (PP, HDPE, LDPE, PVC, PET, ABS), units (kg, mm, CBM, tonnes), currency codes (INR, AED, USD),
Incoterms (FOB, CIF, EXW), CEPA, RoDTEP, GST, IEC, ISO, PIN, and every number. Keep ASCII digits.

Style: plain, respectful (आप / તમે), short sentences, the way a plant manager would say it. Prefer the common English loanword
when that is what people say on the shop floor (मशीन, फ़ैक्टरी, इनवॉइस). Do not invent new words.
